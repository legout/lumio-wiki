# Evaluation questions

Ask these only after the coding agent has published and validated the Knowledge Base. Require citations and inspect the Retrieval Trace where available.

2. What is the nominal output and standard cylinder size of the Aster 12?
3. Who owns installer certification and the Installation Handbook?
